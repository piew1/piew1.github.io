Deploy ใน 7 ขั้นตอน

Google Sheets → Apps Script → Web App → GitHub Pages

  1. สร้าง Google Sheets

    สร้างสเปรดชีตใหม่ชื่อ StockFlow Database แล้วเปิด Extensions → Apps Script

  2. วาง Code.gs

    วางโค้ดไฟล์ Code.gs แทนไฟล์ Code.gs เดิมใน Apps Script Editor

  3. รัน setupSheets()

    เลือกฟังก์ชัน setupSheets แล้วกด Run อนุญาตสิทธิ์ทั้งหมด ระบบจะสร้าง 6 ชีต พร้อมข้อมูลตัวอย่าง 5 แถวใน Products และ Partners

  4. Deploy Web App

    Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone แล้วคัดลอก URL /exec

  5. ใส่ API_URL

    วาง URL ในตัวแปร API_URL ที่ต้นสคริปต์ index.html หรือที่ช่องด้านบน กดทดสอบการเชื่อมต่อ

  6. อัปโหลด GitHub Pages

    อัปโหลด index.html ไว้ที่ root ของ repository แล้วเปิด Settings → Pages → Deploy from branch → main / root

  7. เข้าสู่ระบบและเปลี่ยนรหัส

    ล็อกอิน admin@system.local / Admin@1234 ระบบบังคับให้เปลี่ยนรหัสผ่านทันที ก่อนเริ่มใช้งานจริง

API_URL = "https://script.google.com/macros/s/XXXXXXXXXXXXXXXX/exec"
